# Organization `.github` repository

This repository defines organization-wide defaults for **QuitQui** on GitHub.

## What to put here

- `profile/README.md` — organization profile shown publicly on the org page
- `ISSUE_TEMPLATE/` and `pull_request_template.md` — default templates for repos
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` — community health defaults
- `.github/CODEOWNERS` — default code ownership rules for this repository

## Suggested first steps

1. Add `profile/README.md` with a short org description and key links.
2. Add issue + PR templates to standardize incoming work.
3. Add security/contact policy (`SECURITY.md`) and contribution guidance (`CONTRIBUTING.md`).
